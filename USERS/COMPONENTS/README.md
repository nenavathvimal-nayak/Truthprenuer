# Truthprenuer User UI Components (`USERS/COMPONENTS/`)

## 1. Overview
Reusable Flutter presentation components for the client application.

## 2. Directory Mappings
All implementation widgets reside in [`lib/components/`](file:///Volumes/NAYAK/taeed_flutter_source/lib/components/):
- `adaptive_app_shell.dart`: Responsive shell with offline banner and navigation rails.
- `validation_card.dart`: Interactive validation hypothesis card with upvoting and live counters.
- `evidence_submission_modal.dart`: Multi-step evidence attachment dialog.
- `universal_state_view.dart`: Error, empty, and loading state views with retry CTAs.
- `verification_badge.dart`: Dynamic color-coded truth verdict pill.

## 3. Testing
Tested across mobile, tablet, and desktop form factors in [`test/`](file:///Volumes/NAYAK/taeed_flutter_source/test/).
