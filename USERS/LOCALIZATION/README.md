# Truthprenuer Client Localization (`USERS/LOCALIZATION/`)

## 1. Overview
Multi-language support (i18n and l10n) for global startup founders and validators.

## 2. Configuration
- Default locale: `en_US` (English).
- Fallback locale: `en_US`.
- Formats: ISO-8601 timestamps, internationalized currency (USD, EUR, INR, AED).
- Screen-reader accessible strings across all interactive elements.
